# マルチベンダー E コマース QA テスト観点（厳しめ）

## ドキュメントガイド

- 本文書は高リスク領域のテスト観点を優先度付きで列挙する
- 使い方: P0 / P1 / P2 を基準に優先順位を決める
- 関連: `TESTING_DESIGN.md`（同ディレクトリ）、`../../README.md`

---

## 前提と範囲

| 項目 | 内容 |
|-----|------|
| **対象ロール** | 顧客 / 販売者 / 管理者 |
| **対象機能** | 商品・在庫・注文・決済・配送・レビュー・検索・管理系画面 |
| **外部連携** | Clerk 認証 / Stripe・PayPal 決済 / Cloudinary 画像 / Elasticsearch |
| **最優先** | 破壊的バグ（誤課金 / 在庫破壊 / 権限漏洩 / 個人情報漏洩 / 注文不整合） |

### 重要度の基準

| 優先度 | 基準 |
|--------|------|
| **P0** | 事業停止 / 不正請求 / 重大な権限逸脱 / データ破壊 |
| **P1** | 売上や顧客体験に重大影響（購入不能 / 誤在庫 / 不正な割引） |
| **P2** | 体験劣化や運用負荷増大（表示崩れ / 操作性 / 軽微な不整合） |

## 1. 認証・認可（Clerk / RBAC）

| 優先度 | テスト観点 |
|--------|-----------|
| P0 | ロール横断アクセス（顧客が管理 / 販売者画面に侵入、他店舗の注文 / 商品を参照・編集） |
| P0 | 直接 URL アクセスでの ID 列挙（orderId / productId / storeUrl で他人データ閲覧） |
| P1 | セッション切れ / 二重ログイン / 多端末ログイン時の整合性 |
| P1 | 退会 / 無効化ユーザーのトークン残存・操作継続 |
| P1 | Clerk 退会（user.deleted webhook）と DB の追従整合: 注文/レビュー/住所/店舗持ちユーザーは FK RESTRICT で削除不能 → 500 + Svix 無限リトライ + PII 残存 / Cart・Wishlist は CASCADE 消滅 / SupportTicket は SET NULL 匿名化（2026-07-11 追記・plan 040） |
| P2 | パスワード / 認証周りの UX（リダイレクト・戻る挙動・無限ループ） |

## 4. 検索・カテゴリ・フィルタ

## 20. 重点シナリオ（E2E）

| 優先度 | シナリオ | カバー状況（2026-07-11 R8 実測で追記） |
|--------|---------|----------------------------------------|
| P0 | 顧客が複数店舗の商品を購入 → 正しく分割注文 / 請求 / 在庫更新 | 分割注文 = platform-coupon spec（`Order Id:` ×2）・在庫 = stock-decrement spec で実装済みだが **signIn ドリフトで全滅中（plan 042 修復）**。請求（金額明細表示）は未検証 → **plan 047** |
| P0 | 決済失敗 → カート / 在庫 / 注文状態が完全に巻き戻る | E2E 未着手（Stripe 実キー + 失敗カード前提で deferred — findings-16）。DB 巻き戻しは Integration plan 032 が部分カバー |
| P1 | 販売者が在庫を 0 に変更 → 購入不可が即反映 | E2E なし（販売者ダッシュボード操作は OI-11 先行依存で deferred 維持） |
| P1 | 管理者が店舗停止 → 全商品が非表示 / 購入不可になる | **アプリ側が半分未実装**: store ページは ACTIVE フィルタ済み（→ **plan 050** で E2E 固定）だが `getProducts` に store status 条件が無く BANNED 店舗の商品が /browse に露出（correctness 起票候補 — findings-16 TESTS-38 追記） |

| P2 | ゲストで構築したカートがサインイン後も引き継がれ /checkout に持ち越される | E2E ゼロ（既存は「未認証エラー」と「最初から認証済み」のみ — R9 TESTS-42）→ **plan 055**（plan 042 先行） |

| P2 | ストアフロント主要ページ（browse / 商品詳細 / cart）に WCAG 2.1 AA 違反・レイアウト崩れが無い | a11y / VRT とも対象外だった（R9 TESTS-43/44）→ **plan 052 / 054**（042 Step 4 / 043 先行）。home は OI-9 解消後に追加 |
