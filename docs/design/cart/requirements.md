# Cart — requirements

- 対象: `/cart`（DS-PAGE-007）。2026-10-01。
- ホーム・商品詳細と揃えた深緑、アイボリー、ゴールド、セリフ見出しを使う。
- 空／読み込み／商品入り／在庫切れ／同期失敗／保存中／保存失敗を読みやすく表示する。
- 商品名・バリアント・サイズ・単価・数量・送料内訳・小計・総額を保持する。税額は既存仕様の $0.00。
- 商品選択、全選択、選択削除、個別削除、数量変更、wishlist保存、購入手続きはキーボードで操作でき、focusを表示する。
- 在庫上限で増加を無効化。数量1で減少すると削除する既存動作を保持。
- 削除した明細の送料を集計から除外。同期で消失した商品を除外する既存通知を保持。
- 保存中は再送信を防ぐ。失敗時はカートを保持して再操作できる。
- 同期失敗はローカルのカートを表示し、更新案内と通知を示す。
- 1440/390/768pxで横あふれを起こさず、狭い画面は商品・集計を縦に並べる。
- 空状態は `/browse`、プライバシーと利用規約は `/legal` に実リンクで移動する。
- ストアの react-hot-toast を深緑・ゴールドの通知に統一。成功／エラーのアイコン、読み上げ、閉じる操作、長文折り返し、reduced-motionに対応。
- DBモデル・購入・決済・認証の規則を変更しない。Radix/Sonner通知は別対象。
